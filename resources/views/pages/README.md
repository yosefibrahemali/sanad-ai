# سَنَد AI (Sanad AI)
### منصة ليبية ذكية للدعم النفسي والتواصل مع المختصين
> **"لست وحدك، سَنَد معك"** | **"مساحة آمنة لتتحدث، وتجد من يسمعك"**

نموذج أولي احترافي متكامل (Interactive High-Fidelity Frontend Prototype) مصمم ومبني خصيصًا للمنافسة والعرض أمام لجنة تحكيم الهاكاثون.

---

## مميزات النموذج الأولي

1. **تصميم وهوية بصرية نفسية دافئة**:
   - ألوان مريحة نفسياً: البيج (`#FAF6F0`)، الكريمي (`#F4EFEB`)، البني الترابي الداكن للنصوص (`#271E19`)، ولمسات الأخضر الهادئ (`#4D7258`) والطيني الدافئ (`#BA6446`).
   - خلو تام من الطابع السريري الطبي أو ألوان المستشفيات الباردة.
   - خلو تام من الرموز التعبيرية (Emoji) والاعتماد الحصري على أيقونات SVG دقيقة ورشيقة.
   - هوامش مريحة، حواف منحنية كبيرة (Border-radius: 18px - 36px)، وظلال ناعمة متعددة الطبقات.
   - خطوط عربية حديثة واضحة ومقروءة (`Tajawal` و `Cairo`) مع اتجاه كامل من اليمين لليسار (`dir="rtl"`).

2. **رحلة المستخدم المجهول (Anonymous User Journey)**:
   - **ابدأ بدون اسم**: لا نطلب الاسم، رقم الهاتف، أو البريد الإلكتروني.
   - **محادثة ذكية باللهجة الليبية**: نظام تفاعلي يستجيب بالعبارات الليبية الطبيعية المتفهمة ("نفهمك وخيي/وخيتي"، "الضغط متاع القراية والامتحانات"، إلخ).
   - **لوحة التحليل اللحظي (AI Live Analysis Panel)**: تتبع ديناميكي لمؤشرات الحالة (ضغط نفسي، صعوبة في التركيز، إرهاق، قلق) مع تنبيه عدم تقديم تشخيص طبي.
   - **نتيجة التقييم والخطوات التالية**: مقاييس بصرية، تمرين تنفس تفاعلي متحرك، وإرشادات إدارة التوتر.
   - **المساعد اليومي (Personal Assistant Dashboard)**: فحص المزاج اليومي، تحديد الاحتياجات، وسجل الخواطر المحلي.
   - **دليل المختصين وملفاتهم**: أخصائيون نفسيون ليبيون معتمدون، فلاتر للمناطق (طرابلس، بنغازي، مصراتة، سبها)، ونظام طلب جلسات مجهول.
   - **مجتمع سَنَد**: منصة تضامن آمنة بأسماء رمزية مشفرة (`مستخدم #4821`).

3. **لوحة تحكم الأخصائي وفلسفة Human in the Loop**:
   - تسليط الضوء على مبدأ: **"الذكاء الاصطناعي يساعد المختص، لكنه لا يتخذ القرار النهائي"**.
   - تسلسل إجرائي واضح: `تحليل الذكاء الاصطناعي ← توصية الذكاء الاصطناعي ← مراجعة المختص البشري ← القرار الإكلينيكي النهائي`.
   - جدول الحالات المصنفة (#SN-1042، #SN-1057) مع أزرار القرار وتدوين الملاحظات.

4. **مرصد سَنَد (Aggregated Analytics Observatory)**:
   - لوحة إحصائية مجمعة ومجهّلة بالكامل لدراسة مصادر الضغوط في ليبيا:
     - الدراسة والامتحانات: 38%
     - العمل وبداية المسار المهني: 24%
     - العلاقات والأسرة: 18%
     - الوضع المالي: 12%
     - أخرى: 8%

5. **تصميم متجاوب 100%**:
   - متوافق مع كافة الهواتف والشاشات اللوحية والحواسيب.
   - شريط تنقل سفلي خاص بالهواتف (Mobile Bottom Navigation).
